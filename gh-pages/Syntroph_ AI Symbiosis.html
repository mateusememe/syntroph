Syntrophy, the biology

One organism’s metabolic output feeds the other.

In biology, syntrophy is symbiosis where the waste of one life form becomes the fuel of another. Syntroph applies the same law to software agents.

Metabolism · Context

Every trace is biomass

Each agent leaves behind context, search traces, plans and refactored code. Instead of burning that energy, Syntroph harvests it into shared memory.

Symbiosis · Continuity

Excess becomes fuel

What one agent produces — a resolved bug, a forged abstraction, a hard-won design decision — becomes living context that nourishes every subsequent agent in the network.

Evolution · Learning

The whole system grows

Your agents stop working in isolation. The graph remembers, adapts and compounds, so each session starts stronger than the last.

Capabilities

One living substrate for every agent.

Not another plugin. A nervous system your coding agents share.

01 · memory

Shared Evolving Memory

One continuous, versioned memory that persists across every agent, session and tool. Nothing worth remembering is ever lost.

02 · graph

Code-Knowledge Graph

Files, functions, decisions and their rationale linked as nodes and synapses — so agents navigate meaning, not just text.

03 · orchestration

Multi-Agent Orchestration

Route work across Claude Code, Codex and Antigravity CLI — each doing what it does best, all feeding the same graph.

04 · continuity

Context Continuity

Agents wake up with full situational awareness. No more re-explaining your codebase to a stranger who "doesn't remember".

05 · privacy

Local-First / Private

Your graph lives on your machine. Full context, zero exfiltration. The intelligence is yours — no third-party black box.

06 · open

Extensible & Open Source

MIT-licensed core with a plugin API for new agents, memory stores and graph backends. Built in public, improved by many.

Orchestrated agents

  • Carries long-lived memory across sessions

Configuration

Wire them up in one file.

Declare your agents, point them at a shared memory store, and let the graph evolve.

syntroph.config.ts 
 1import { defineConfig } from "syntroph";
 2
 3export default defineConfig({
 4  memory: {
 5    store: "local-graph",        // private, on-device
 6    evolve: true,               // memory grows each run
 7    sync: ["claude", "codex", "antigravity"],
 8  },
 9
10  agents: [
11    { id: "claude",      tool: "claude",      role: "architect" },
12    { id: "codex",       tool: "codex",       role: "explorer"  },
13    { id: "antigravity", tool: "antigravity", role: "executor" },
14  ],
15
16  graph: {
17    seed: true,                    // index codebase up front
18    connect: "semantic",          // link by meaning, not path
19    prune: { staleAfterDays: 30 },
20  },
21});
