# Domain documentation

This is a single-context repository.

Before exploring or changing domain behavior:

- Read `CONTEXT.md` at the repository root.
- Read the relevant decisions in `docs/adr/`.
- Use the glossary's canonical vocabulary in issues, specs, tests, and design notes.
- Surface contradictions with existing ADRs instead of silently overriding them.

Keep `CONTEXT.md` as a glossary, not an implementation spec. Record difficult-to-reverse, surprising trade-offs in ADRs.
